# Surface: Interlock app (prototype)

Mode: Operate. Scope: home composer, task chat, worktree panel, automations, project settings, command palette.
Audience/job: engineers handing coding tasks to agents across repos, then steering, reviewing and merging.
Constraints: stub data, nothing real runs; one agent per task.
History: railway theme rejected; dark Linear/Codex canon rejected as "too much"; owner pinned Manus (Refero site 843) as the reference.

## Direction contract

THESIS: Hand a task to an agent the way you would to a capable colleague: a calm page, one question, then a readable account of what it did and a window into its machine. Refuses dashboards, columns and multi-agent arenas.

OWN-WORLD: Manus dark: graphite rail #1d1d1c, page #262625, lighter cards #313130 with soft dark shadows, light ink primary buttons. Libre Baskerville for the headline, wordmark and decision titles; system UI sans for everything else; Geist Mono for code and branches. Dark ink pill buttons. Status colour only on small icons.

STORY: Type a task on the home composer, watch the agent's steps fill in, answer its questions inline, open its worktree to read the changes, create the PR.

FIRST VIEWPORT: Sidebar (wordmark, New task, Automations, Search, Library, Projects, All tasks, tracker card). Main: model picker top-left, account controls top-right, centered serif "What should we build?", white composer with project/branch/Plan first, "Connect your tools" strip, template chips.

FORM: Canon pinned to a named reference (Manus via Refero), adapted to coding agents. Prior seed 721856ec superseded.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
